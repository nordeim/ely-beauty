## The lesson

The run-108 lesson ("a remediation class deserves a net at every stratum its residue can reach") recurs at the deepest stratum yet — **the operator's own artifacts**: `start_server_log.txt` is operator-generated, operator-committed content that no code review ever gates, and it carried the highest-value secret in the system across 107 audits because the secrets sweep was built on MARKERS while secrets leak in SHAPES. The countermeasure's two design rules generalize: (1) a secrets net bans the SHAPE and never quotes the value (a net carrying the toxin it bans is itself a leak); (2) the corpus floor proves the net SCANNED (a broken enumeration passing vacuously is the over-scoping class inverted). And the standing truth for any committed secret: the in-repo redaction is the HALF-fix — git history retains the value forever, so the complete fix is rotation at the source, and the advisory must ride every artifact the operator reads (the plan, the worklog, this log, the commit message, the final reply).
