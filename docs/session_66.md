**Lessons for the next cycle:** the run-104 lesson ("an invariant nobody probes is a claim nobody checked") generalizes past grammars: **a formatter's NAME can outlive its DOMAIN.** `formatMoney` was the money formatter, so the Stripe retrofit reached for it — but the function's contract is ৳ BDT poisha, and Stripe amounts are USD minor units; the ported seam imported the label along with the formatting, and every pin since baked the mislabel in as expected output. When a new money DOMAIN joins a codebase (a second currency, a different minor unit), the seam that renders it needs its own named formatter with its own pins — and an audit that re-derives expected values from the DOMAIN (what currency IS this number?) rather than from the existing pins (what does the current code print?) is the only probe that catches the class; the pinned fixtures of a defect are its best camouflage.
